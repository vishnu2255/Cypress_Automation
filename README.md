# Cypress Automation Project

This is a Cypress automation project written in TypeScript for end-to-end testing.

## Project Structure

```plaintext
cypress_automation/
├── cypress/
│   ├── e2e/                # End-to-end test files
│   ├── fixtures/           # Test data
│   ├── reports/            # Test reports
│   ├── selectorsRepo/      # Page object files
│   │   └── dashboard.ts    # Example page object file
│   └── support/            # Custom commands and helper files
│       ├── commands.ts     # Custom Cypress commands
│       └── helper.ts       # Helper functions
├── node_modules/           # Dependencies
├── cypress.config.ts       # Cypress configuration file
├── package.json            # Project dependencies and scripts
├── tsconfig.json           # TypeScript configuration


Prerequisites:

Node.js: Install Node.js (v16 or higher).
npm: Comes bundled with Node.js.


Clone the repository:
git clone 
cd cypress_automation

Install dependencies:
npm install
